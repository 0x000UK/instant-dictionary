Merriam-Webster optional

One of the most authoritative English dictionaries. Connecting it adds audio pronunciation playback and richer definitions for single words. MW offers two separate API keys — a Collegiate Dictionary key and a Thesaurus key — both free, each with up to 1,000 lookups per day. You may enter one or both; when both are saved a toggle button appears in the definition tooltip so you can switch between sources on demand.

Register for free API keys at dictionaryapi.com →

STANDS4 optional

Specialises in idioms, phrasal verbs, and expressions that standard dictionaries often miss (e.g. "kick the bucket", "on the fence"). Both the idiom and vocabulary endpoints are included with a free account.

Get your free API key by signing up at STANDS4's Phrase API →
