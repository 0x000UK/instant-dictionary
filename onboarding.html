Welcome to Instant Dictionary

Experience uninterrupted reading. Instant Dictionary delivers definitions for unfamiliar words and phrases directly inline, entirely eliminating the need for context-switching, new tabs, or external searches. The lookup tooltip appears instantly alongside your selection and automatically dismisses itself. It is fully compatible with standard webpages, articles, documentation, web PDFs, and local documents.

⚠️ IMPORTANT NOTE: A brief visual flash of the dictionary sidebar opening and closing upon browser launch is expected behavior. This occurs exclusively if Firefox was closed while the sidebar was active, and is an unavoidable artifact of Firefox's native Session Restore sequence.

Trigger Methods

The extension is designed for seamless activation. Choose the method that best fits your workflow:

  • Double-Click: Select any single word to immediately view its definition.
  • Click and Drag: Highlight a word or phrase to reveal a contextual Define pill. Clicking this pill prevents unwanted lookups when you simply intend to copy text.
  • Context Menu: Highlight your text, right-click, and select "Define '...'" from the native browser menu.
  • Keyboard Shortcut: Highlight text and press Alt+Q to launch the dictionary instantly.
  • Sidebar Access & Search: Press Alt+W (Mac: Cmd+W) at any time to toggle the Instant Dictionary sidebar. From here, you can manage local files or use the dedicated search bar to manually look up any word.
Firefox Reader Mode Limitations: Within Firefox's Reader Mode (about:reader), double-clicking and keyboard shortcuts are restricted. To lookup a word in Reader Mode, you must highlight the text, open the right-click Context Menu, and select "Define".

Dismissing the UI: The Tooltip automatically closes after 6 seconds to stay out of your way (hovering pauses this countdown). You can close the Tooltip manually by clicking the × button on its header, clicking anywhere outside of it, pressing Escape, or pressing Alt+Q. To close the Sidebar, press Alt+W again or click the native × button on the Firefox sidebar header.

Document Viewing: PDFs & Local Files

Modern browsers implement strict security policies that prevent extensions from operating on local files or within native PDF viewers. To bypass this limitation, Instant Dictionary includes an integrated, secure document viewer.

  • Web PDFs: The extension actively intercepts PDF links clicked on the web. Before the default viewer can open, the document is routed into our custom viewer, ensuring the dictionary is fully initialized and ready the moment the document renders.
  • Local Documents: Press Alt+W (Mac: Cmd+W) to open the sidebar. Click the Open Local Files button and either browse or drag-and-drop your document. Full support is currently available for PDFs, with EPUB and DOCX capabilities in active development.

Seamless File Management

To make reading local files effortless, the extension remembers your five most recently opened documents for quick access, automatically switches you to the correct tab if a file is already open to prevent clutter, and saves your exact page and scroll position so you can pick up exactly where you left off after restarting your browser.

Sources & API Configuration

Instant Dictionary operates out-of-the-box utilizing publicly available sources. However, users can unlock premium features—such as native audio pronunciations and extensive idiom coverage—by configuring free API keys within the extension's popup menu.

Source Integrations Capabilities & Features
Free Dictionary API & Wiktionary Default sources requiring zero setup. Delivers clean, structured data for common terminology, proper nouns, technical jargon, and includes free audio. Features a ⇄ toggle button inside the tooltip for seamless switching between the two free sources.
Merriam-Webster Collegiate / Learner's The superior primary fallback engine. Provides authoritative definitions and features a 🔊 Listen button for native audio pronunciation.
Merriam-Webster Thesaurus Provides synonyms and activates the ⇄ toggle button for Merriam-Webster results, allowing seamless switching between Collegiate and Thesaurus entries.
STANDS4 Vocabulary & Phrases An absolute last-resort fallback. Because it is crowdsourced, it can contain noise, but it specializes in idioms, phrasal verbs, and colloquial expressions.

Lookup Priority Options

You can fine-tune query behavior via the Settings menu:

  • Standard (Default): Queries public sources first. When configured, Merriam-Webster serves as the primary fallback, and STANDS4 acts strictly as a final, last-resort attempt.
  • Enhanced: Executes Merriam-Webster first (when configured), failing over to public sources. STANDS4 (when configured) remains quarantined as the absolute final safety net.

Usage Tracking & Activity Logs

If you choose to configure premium API keys, the extension provides built-in tools within the popup menu to help you effortlessly monitor your daily search limits, set personalized usage caps, and view a brief history of your recent lookups.
